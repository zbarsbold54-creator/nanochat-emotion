# Paper

This directory contains a sourced, working manuscript draft. It is not a
publication-ready paper: analysis is incomplete, citations remain to be
verified, and several pre-registered items are still open.

**Status: this paper is a draft with unverified claims** (see paper/OPEN_ITEMS.md). 
Results are toy-scale (d_model=64, batch=2) and mostly single-config; limits are in 
paper/LIMITATIONS.md and the main project LIMITATIONS.md.

## Current files

| File | Contents |
|---|---|
| `DRAFT.md` | Current neutral RDA manuscript draft |
| `claims.md` | Claim-by-claim source paths and line/key locators |
| `OPEN_ITEMS.md` | Unverified items, placeholders, missing citations, and source conflicts |

`RESULTS.md`, `METHODS.md`, `EXPERIMENTS.md`, and `LIMITATIONS.md` began as
planning notes and are not the source of truth for the manuscript's current
results. Follow the locators in `claims.md` back to the research and result
records. Do not treat this toy-scale study as evidence of subjective emotion.
